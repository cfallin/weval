## weval has moved to the Bytecode Alliance!

weval began as a personal project in
[cfallin/weval](https://gtihub.com/cfallin/weval) but is now a Hosted Project
of the [Bytecode Alliance](https://bytecodealliance.org/) at
[bytecodealliance/weval](https://github.com/bytecodealliance/weval). Please use
that repository as the new usptream and file issues and PRs there as needed!
